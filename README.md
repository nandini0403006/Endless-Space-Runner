Endless Space Runner
A fast-paced 2D endless runner game built from scratch using Python and Pygame.

🚀 About the Game
Navigate your spaceship through an asteroid field, dodge enemies, and collect power-ups. This version includes a fully realized game loop with increasing difficulty, a skin shop, achievement systems, and persistent data saving.

🛠️ Technologies Used
Language: Python
Engine: Pygame
Data Storage: JSON (for save games and leaderboards)

🎮 How to Play
Clone this repository.

Ensure you have Python and Pygame installed (pip install pygame).

Run the game: python endless_space_runner.py

Controls: Use Arrow Keys to move, Spacebar to shoot/jump.
